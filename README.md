# Pwned Checker 🔐

Проверка паролей по базе утечек [HaveIBeenPwned](https://haveibeenpwned.com/Passwords) — **без отправки самого пароля**. Плюс генератор стойких паролей и оценка энтропии.

Чистый Python, **ноль зависимостей** — только стандартная библиотека.

## Как работает k-anonymity

Обычный вопрос: «как проверить пароль по базе утечек, не отправив его владельцу базы?» Ответ — схема k-anonymity:

1. На твоём компьютере считается `SHA-1` от пароля
2. Наружу уходят **только первые 5 символов хэша** (2¹⁰ = ~1 млн вариантов)
3. API возвращает список хэш-суффиксов, начинающихся с этих 5 символов
4. Совпадение ищется **локально**, у тебя на машине

Сервер никогда не видит ни пароль, ни его полный хэш — он даже не может понять, нашли ли вы совпадение: запрос с заголовком `Add-Padding` дополнен случайными суффиксами, и размер ответа всегда одинаков.

```
Пароль:  Tr0ub4dor&3
SHA-1:   0A4E0DA0F37A0F4F0C39B8A79D9E1E9F5F3F9F2B  ← считается локально
Наружу:  https://api.pwnedpasswords.com/range/0A4E0  ← только 5 символов
```

## Возможности

- ✅ **Проверка пароля** — ввод скрыт (`getpass`), пароль нигде не сохраняется
- ✅ **Анализ шаблонов** — клавиатурные и алфавитные последовательности (`qwerty`, `1234`), повторы, топ распространённых паролей (включая leet-варианты `P@ssw0rd` и латиницу русской раскладки `gfhjkm`), приписанные годы — энтропия пересчитывается с их учётом
- ✅ **Пакетная проверка** из файла (по одному паролю на строку) + итоговый рейтинг самых слабых
- ✅ **Генератор паролей** — криптографическая случайность (`secrets`, не `random`), выбор классов символов, исключение похожих (`l`/`1`/`I`, `O`/`0`)
- ✅ **Генератор парольных фраз** — произносимые псевдослова, ~100 бит при 4 словах, легко запомнить и продиктовать
- ✅ **Оценка энтропии** и времени подбора по 4 моделям атак
- ✅ Повторы запросов при сбоях сети, аккуратная обработка Ctrl+C, работа через пайпы
- ✅ Умный вывод с цветом в консоли Windows / Linux / macOS

## Запуск

Требуется Python 3.7+:

```bash
python main.py
```

## Пример вывода

```
=== Проверка пароля ===
Пароль (Enter — отмена): ********

  База утечек : найден в 3 614 утечках
  Длина       : 11 символов, алфавит ~94 символов
  Энтропия    : 72.1 бита → 19 бит с учётом шаблонов
    ! распространённое слово «summer» с приписками — генераторы подбора пробуют такое первым делом
    ! похоже на год (19xx/20xx) — типичная приписка
  Полный перебор по моделям атак:
    - онлайн, ограничение (100 попыток/час): 218 дн
    - онлайн, без ограничений (10 попыток/сек): 15 ч
    - оффлайн, медленный хэш bcrypt (10 тыс/сек): 52 сек
    - оффлайн, SHA-1 на GPU-ферме (100 млрд/сек): мгновенно

  Вердикт: ⛔ НАЙДЕН В УТЕЧКАХ (3 614 раз) — сменить немедленно
```

Длина и классы символов сами по себе ничего не гарантируют: `Summer2024!`
выглядит солидно (72 бита по наивной формуле), но состоит из словарного
слова и года — и наивную оценку приходится урезать до 19 бит.

```
=== Генератор паролей ===
  Vm8qL2xKXN+hV{jk  (104.9 бита)
  >zMngqy4+=*4=5+T  (104.9 бита)
  [g7{yVZLlAeT)]eW  (104.9 бита)
```

```
=== Генератор парольных фраз ===
  бёжюго-Золикя-вётюхи-Зэцыцо8  (99.9 бита)
  вератю-Мяфикю-гяжесю-Зечыму6  (99.9 бита)
```

Фразы собираются из псевдослов («согласный-гласный» × 3 слога), поэтому
их пространство вариантов известно точно — словарной атаки против
«настоящих слов» нет, а продиктовать такой пароль по телефону реально.

## Модели атак

Время подбора считается для четырёх сценариев — от защищённого сервиса с лимитом попыток до GPU-фермы, перебирающей SHA-1 со скоростью 100 млрд хэшей в секунду:

| Модель атаки | Скорость |
|---|---|
| Онлайн с ограничением | 100 попыток/час |
| Онлайн без ограничений | 10 попыток/сек |
| Оффлайн, bcrypt (медленный хэш) | 10 000/сек |
| Оффлайн, SHA-1 на GPU | 100 000 000 000/сек |

Именно поэтому везде, где важно, используют медленные хэши (bcrypt, Argon2): они замедляют перебор в миллионы раз.

## ⚠️ Важно понимать

- «Не найден в утечках» ≠ «безопасен»: уникальный пароль всё равно могут украсть фишингом, кейлоггером или с самого сайта. **Включай двухфакторную аутентификацию.**
- Пакетная проверка читает пароли из файла — удаляй его после проверки.
- Один и тот же пароль на разных сайтах = домино: утечка одного уронит все аккаунты. Пользуйся менеджером паролей.
